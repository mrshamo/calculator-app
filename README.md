
# Java Calculator App 🧮

## 📌 About the Project

CalculatorApp is a simple calculator application built using Java. It performs basic arithmetic operations on two numbers entered by the user.

This project was created to practice Java programming concepts, including user input, switch statements, conditional statements, and arithmetic operations.

## ✨ Features

* Addition (+)
* Subtraction (-)
* Multiplication (*)
* Division (/)
* Takes decimal numbers as input
* Handles division by zero
* Takes user input through the console

## 🛠️ Technologies Used

* Java
* Java Scanner Class
* Switch Statement
* If-Else Statement
* Try-with-Resources

## 📋 Requirements

* Java Development Kit (JDK) installed
* A code editor such as VS Code or IntelliJ IDEA

## 🚀 How to Run

**Step 1: Clone the Repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**Step 2: Open the Project Folder**

```bash
cd CalculatorApp
```

**Step 3: Compile the Java Program**

```bash
javac CalculatorApp.java
```

**Step 4: Run the Application**

```bash
java CalculatorApp
```

## 💻 Example Output
